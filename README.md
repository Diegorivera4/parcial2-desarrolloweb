Crear una página web inspirada en la temática de Disney, siguiendo las buenas prácticas de maquetación web y organización de archivos.  


El resultado final debía representar un sitio informativo que mostrara diferentes secciones como:


- Encabezado con menú de navegación, buscador y botones interactivos.
  
- Banner principal con imagen destacada.
  
- Sección de estrenos o próximos lanzamientos.
  
- Espacios promocionales como los parques Disney o beneficios Visa Disney.
   
- Pie de página con información complementaria.
